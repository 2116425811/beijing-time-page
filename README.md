# beijing-time-page

A minimalist single-page website that displays the current Beijing time (UTC+8), centered on screen and updated every second.

## GitHub Pages deployment

This repository includes `.github/workflows/pages.yml`, which deploys the site from the repository root using GitHub Actions.

To publish it:
1. In GitHub, open **Settings → Pages**.
2. Set **Source** to **GitHub Actions**.
3. Push to `main` (or run the workflow manually from the **Actions** tab).

The default landing page is `/index.html`.
